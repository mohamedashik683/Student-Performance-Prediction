# 🎓 Student Performance Prediction

A Machine Learning based web application that predicts a student's final marks using academic and personal factors.

## 📌 About the Project

This project uses Machine Learning to predict student final marks based on:

- Study Hours
- Attendance
- Previous Marks
- Assignment Marks
- Internal Marks
- Sleep Hours

The application is built using Python and Streamlit.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Linear Regression

## 🚀 Features

- Predicts final student marks
- Shows performance level
- Provides basic recommendations
- Displays student performance analysis charts
- Shows Machine Learning model evaluation metrics

## 📊 Machine Learning Model

The project uses **Linear Regression** for predicting final marks.

Evaluation metrics used:

- Mean Absolute Error (MAE)
- R² Score
